# Naval High-Pressure Hydraulic Steering & Rudder Actuation System
**Document ID:** NAV-SPEC-HYD-450 | **Type:** engineering_specification

---

## Hydraulic Pump Unit HPU-1: System Overview and Pressure Ratings

Engineering specification for Hydraulic Pump Unit HPU-1 in the Hydraulics domain. The subsystem operates under nominal system pressure of 210 bar gauge, with hydraulic fluid MIL-PRF-17672D. Operating temperature envelope is restricted between -10°C and +70°C. Maximum allowable flow velocity through the primary distribution line is 4.5 m/s. Periodic hydrostatic testing must be conducted every 36 months at a proof test pressure of 315 bar gauge. Seal degradation inspection requires replacement of fluorocarbon O-rings if compression set exceeds 22%.
